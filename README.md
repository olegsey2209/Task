# TaskPlanner

iOS-приложение для планирования личных дел.

## Требования
* macOS
* Xcode 16 или новее
* iOS Simulator или физическое iOS-устройство (iOS 18.5 и новее)

## Установка и запуск

1. Клонировать репозиторий: 
2. Открыть файл `TaskPlanner.xcodeproj` в Xcode.
3. В Xcode выбрать iOS Simulator (например, iPhone 15) или подключить через провод свое iOS-устройство.
4. Нажать кнопку «Run».
5. После сборки приложение запустится в симуляторе или на вашем  iOS-устройстве.
